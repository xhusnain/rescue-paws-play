# Rescue Paws

A pull-the-pin bath puzzle built for YouTube Playables.

**▶ Play: https://xhusnain.github.io/rescue-paws-play/**

Pull the pins to route clean water into the tub, keep the mud out, and pop three
bubbles on the way. 30 levels across 3 chapters, 6 unlockable pets.

- Built with the YouTube Playables SDK (interstitial + rewarded ads integrated)
- 53 KB total, no image or audio assets — all art is canvas-drawn, all sound synthesised
- Works on touch, mouse and keyboard, at any aspect ratio from 9:32 to 32:9

This repository hosts the playable build. Outside the Playables environment the
game falls back to local storage for saves.
